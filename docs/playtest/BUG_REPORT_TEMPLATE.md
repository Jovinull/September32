### Optional, and very useful

**Screenshot.** Especially if text was cut off, overlapping, or unreadable.

**The error text.** If Ren'Py showed you a black error screen, the text on it is
the single most useful thing in this form. The same text is in `errors.txt` next
to the game, and `traceback.txt` has a longer version.

**Your save file.** From your save folder — `%APPDATA%\RenPy\September32-1` on
Windows, `~/.renpy/September32-1` on Linux. A save from just before it happened
is better than one from after.

**Your playtest report.** `playtest-report.json`, if you kept one. It contains
the seed of your run, which means the same week can be replayed exactly.
