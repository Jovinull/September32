# Doki Doki Literature Club

Original analysis. No content from the work is reproduced here.

## USE FOR

**Only two things.**

**Genre expectation as a resource.** It establishes a register precisely, then
uses the reader's confidence in it.

**Escalation from within the familiar.** The first departure is small and
deniable.

## DO NOT COPY

**Everything else, explicitly.** The file manipulation, the fake crashes, the
fourth-wall breaking, the character addressing the player, the desktop horror,
the specific structure, any character, the club premise.

This is written down as a rule rather than an instinct, because it is the
reference most likely to be borrowed from carelessly.

## PRINCIPLE

> Establish a register the audience trusts, then depart from it by the smallest
> amount that is still noticeable.

## RELEVANCE TO SEPTEMBER 32

The `normal → odd` transition. The first thing that does not fit is a stamp,
read twice. Small, deniable, and noticed by the player before it is remarked on
by anyone.

`docs/narrative-design/META.md` rules out everything else in explicit detail —
not because it was done badly, but because it has become a genre. A game
reaching for those techniques is instantly read as being *about* that genre
rather than about itself.

## RISKS

**The obvious one.** Any meta-horror in a school-set VN with an escalating tone
invites the comparison. The defence is not subtlety; it is that this game's
unease is archival and inferential (rule R4 — the phenomenon never performs) and
never touches the player's machine.
