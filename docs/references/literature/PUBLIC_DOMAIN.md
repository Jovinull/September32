# Public-domain corpus policy

## The decision

**No full texts are stored in this repository.**

Every work in `docs/references/literature/` is public domain in both the United
States (published before 1930) and in life+70 jurisdictions (all seven authors
died before 1956). Downloading them would be lawful.

They are not downloaded anyway, because the project does not need them. What is
useful here is *analysis* — what each work does and how — and that is written by
someone who has read it. Storing a corpus we would not read again would add
megabytes and a maintenance question in exchange for nothing.

## If that changes

Should a genuine need arise — a stylometric tool, a study of sentence rhythm —
texts go in `research/public-domain/`, which is committed, with a manifest
recording per work:

```
title
author
original_year
author_death_year
public_domain_basis     the specific reason, per jurisdiction
source                  Project Gutenberg, Standard Ebooks, or similar
source_url
retrieved_at
sha256
```

And the rules:

1. **Verify the jurisdiction.** "Public domain" is not a global property. Record
   the basis for each, separately.
2. **Reputable sources only.** Project Gutenberg, Standard Ebooks, Wikisource,
   a library digitisation programme. Not a random text file.
3. **Never store a work still in copyright.** No exceptions, no "just for
   analysis", no temporary copies.
4. **Public domain in the work, not the edition.** A modern annotated edition has
   its own copyright in the annotations, the introduction and often the
   typesetting. Take the plain text.
5. **When in doubt, do not.** The analysis is what the project actually uses.
