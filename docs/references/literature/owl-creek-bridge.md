# An Occurrence at Owl Creek Bridge

**Ambrose Bierce, 1890.** Author died 1914 (disappeared).

**Public-domain basis:** published before 1930 (public domain in the United
States), and more than 70 years after the author's death (public domain in
life+70 jurisdictions). Verified 2026-08-30 — see
`docs/references/literature/PUBLIC_DOMAIN.md` for the corpus policy.

Original analysis. No text from the work is reproduced here.

## USE FOR

**Recontextualisation in a single stroke.** The final line changes everything
preceding it, and rereading confirms that everything was there.

**Subjective time.** Duration as experienced rather than measured.

**Sensory over-specificity as a signal.** The prose becomes *more* detailed
exactly where it becomes least reliable — which is the tell, placed in plain
sight.

## DO NOT COPY

The execution, the escape, the ending device itself. It has been imitated so
often that using it now announces itself.

## PRINCIPLE

> A recontextualisation only works if it was all there the first time. Anything
> else is a cheat, and readers can tell.

## RELEVANCE TO SEPTEMBER 32

The test for every reveal this game plans: could an attentive player, rereading,
find that it was all present? `docs/style/MYSTERY.md` states it as fair play.

The subjective-time idea is unexpectedly close to the premise. A day that some
people experienced and others did not is one of the hypotheses in
`docs/canon/SEPTEMBER_32.md`, and Bierce is the argument that it can be done
without cheating.

## RISKS

**The device is worn out.** "It was not real" as an ending is ruled out.
`docs/style/MYSTERY.md`: a twist that invalidates the evidence is a refusal, not
a resolution.
