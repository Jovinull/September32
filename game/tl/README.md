# Translations

Empty. The game is not translated yet; what is done is the preparation.

`game/tl/<language>/` is generated by Ren'Py:

```
<sdk>/renpy.sh . translate pt_br
```

Re-running adds only what is new and preserves existing translations.

The workflow, the rules for writers, and the one open design question
(a protagonist with no stated gender, in a language whose adjectives agree) are
in `docs/production/LOCALIZATION.md`.
